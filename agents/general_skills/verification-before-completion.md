# Verification Before Completion
Mandatory verification gate before claiming work is complete. Requires fresh evidence (test output, build output, linter output) before any success claim

**Triggers:** verification, completion check, done, ready to commit, tests pass, build succeeds, linter clean, before commit, before PR, before merge
