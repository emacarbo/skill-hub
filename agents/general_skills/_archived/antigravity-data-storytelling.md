# Data Storytelling

Craft data-driven narratives that move audiences from insight to action. Combines three pillars -- Data (evidence), Narrative (meaning), and Visuals (clarity) -- into a story arc: Hook, Context, Discovery, Recommendation, Call to Action.

## Key Patterns

- **Lead with the "so what"**: Start with the insight, not the methodology -- "We're losing $2.4M to preventable churn" beats "Q4 Churn Report"
- **Story structure**: Setup (context/baseline) -> Conflict (problem/opportunity) -> Resolution (insights + recommendations)
- **Headline formula**: `[Specific Number] + [Business Impact] + [Actionable Context]`
- **Progressive reveal**: Build complexity one layer at a time -- single metric -> trend -> breakdown -> root cause -> recommendation
- **Rule of three**: Three key points, three comparisons, three recommendations -- audiences retain groups of three
- **Contrast and compare**: Before/after, this vs. that, benchmarks -- differences create narrative tension
- **Annotate key moments**: Mark inflection points, events, and thresholds directly on charts
- **Acknowledge uncertainty**: Report confidence intervals, sample sizes, and caveats -- credibility builds trust
- **End with a clear ask**: Budget approval, resource allocation, timeline decision -- never end without next steps
- **Match audience vocabulary**: No jargon for executives; technical depth for analysts

## Quick Reference

### Executive Presentation Flow

```
Slide 1: THE HEADLINE  -- One-sentence insight with impact number
Slide 2: THE CONTEXT   -- Current state, benchmarks, gap analysis
Slide 3: THE DISCOVERY -- What the data revealed (key chart)
Slide 4: THE DEEP DIVE -- Root cause, segments, significance
Slide 5: THE SOLUTION  -- Proposed actions, resources, timeline
Slide 6: THE IMPACT    -- Expected outcomes, ROI, risk assessment
Slide 7: THE ASK       -- Specific decision needed, next steps
```

### Headlines -- Bad vs. Good

- "Q4 Sales Analysis" -> "Q4 Sales Beat Target by 23% -- Here's Why"
- "Customer Churn Report" -> "We're Losing $2.4M to Preventable Churn"
- "Marketing Performance" -> "Content Marketing Delivers 4x ROI vs. Paid"

### Transition Phrases

| Purpose | Phrases |
|:--------|:--------|
| Building | "When we dig deeper...", "The pattern becomes clear when..." |
| Insight | "What surprised us was...", "The inflection point came when..." |
| Action | "This insight suggests...", "Based on this analysis..." |
| Uncertainty | "With 95% confidence...", "While correlation is strong, causation requires..." |

### One-Page Dashboard Template

```
HEADLINE: Revenue up 15% but CAC increasing faster than LTV

KEY METRICS:  MRR $125K (+15%)  |  NRR 108% (+3%)  |  CAC $450 (+22%)  |  LTV $2,200 (+8%)

WHAT'S WORKING:              WHAT NEEDS ATTENTION:
+ Enterprise growing 25% MoM  - SMB acquisition cost up 40%
+ Referrals drive 30% new     - Trial conversion down 5 pts
+ Support sat at 94%          - Time-to-value up 3 days

ROOT CAUSE: [chart] SMB paid ads less efficient -- CPC +35%, conversion flat

RECOMMENDATION: 1) Shift $20K/mo to content  2) Launch SMB self-serve  3) A/B test onboarding
```

### Do's and Don'ts

| Do | Don't |
|:---|:------|
| Lead with the "so what" | Data dump without narrative |
| Use the rule of three | Bury the insight in methodology |
| Show, don't tell (let data speak) | Use jargon with non-technical audiences |
| End with a clear ask | Forget the call to action |
| Annotate key chart moments | Present raw tables without context |

## When to Use

- Presenting analytics or dashboards to executives or non-technical stakeholders
- Creating quarterly business reviews or investor presentations
- Writing data-driven reports that need to drive a specific decision
- Communicating surprising findings or recommending a course of action
- Building one-page dashboard narratives that combine metrics with context
